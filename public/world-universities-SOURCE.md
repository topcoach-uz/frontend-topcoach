# University suggestions

`world-universities.json` is a snapshot downloaded on 2026-09-07 from
https://github.com/Hipo/university-domains-list/blob/master/world_universities_and_domains.json

Distributed under the MIT license; see `world-universities-LICENSE.txt`.
The directory provides name suggestions for prior education. It is not an
accreditation or admissions-program database. Custom entries remain supported.

The file is served locally with the application; user searches are not sent to
the directory provider. TopCoach's own university catalog supplements this list.
